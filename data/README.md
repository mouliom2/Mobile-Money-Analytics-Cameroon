# Données

Ce projet utilise uniquement des **données synthétiques** créées pour un portfolio Data Analyst.

- `raw/mobile_money_analytics_cameroon.xlsx` : classeur Excel pédagogique.
- `raw/mobile_money_transactions_cameroon.csv` : données transactionnelles au format CSV.
- `database/mobile_money_cameroon.db` : base SQLite normalisée.

Aucune donnée réelle de MTN, Orange, d'un client ou d'un agent n'est utilisée.
